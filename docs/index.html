// 02 — concerne uniquement la méthode B (.exe)

« Microsoft Defender SmartScreen a empêché le démarrage »

✓ Vous n'avez pas ce problème si vous utilisez la méthode A

SmartScreen ne s'active que sur un exécutable téléchargé par un navigateur (Windows y colle la marque « Mark of the Web »). La commande PowerShell ne fait qu'appeler Invoke-WebRequest : les fichiers récupérés n'ont aucune marque, Unblock-File la retire au besoin, et aucun .exe n'est exécuté. Le payload installé est du simple JavaScript chargé par Discord — rien que Windows puisse bloquer.

⚠ Ce n'est pas un virus

Cause : noxtcord.exe est un exécutable non signé numériquement et téléchargé depuis Internet. Windows applique la marque « Mark of the Web » et SmartScreen bloque tout binaire inconnu. C'est le comportement par défaut de Windows pour n'importe quel exe sans réputation.

  1. Depuis la fenêtre d'avertissement : cliquez sur Plus d'informations → Exécuter quand même.
  2. Ou débloquez le fichier une bonne fois pour toutes : clic droit → Propriétés → cocher Débloquer → OK.
  3. Ou en PowerShell : Unblock-File -LiteralPath "C:\chemin\vers\noxtcord.exe"

Solution définitive : la signature du code via SignPath (gratuite pour les projets open source) + soumission du fichier à Microsoft.

✓ Après l'installation

Rien n'est supprimé ni modifié en dehors de Discord : l'app.asar d'origine est sauvegardé en _app.asar. Un simple désinstallateur remet tout dans l'état initial.

// 03 — comment ça marche

Quatre étapes, toutes réversibles

1

Sauvegarde

L'installateur renomme resources\app.asar en _app.asar. Ton Discord d'origine est intact et restaurable à tout moment.

2

Mini-app.asar

Un tout petit app.asar est écrit : son index.js fait simplement require("%APPDATA%\Noxticord\dist\patcher.js").

3

Copy du payload

Le contenu de payload/ (patcher, bundles, CSS) est copié dans %APPDATA%\Noxticord\dist depuis GitHub.

4

Relance

Discord redémarre, le build NoxtiCord prend le relais. Un toast « Mettre à jour et redémarrer » apparaît dès qu'une nouvelle version est publiée.

Après une mise à jour DiscordAction
La catégorie NoxtiCord a disparunode installer.mjs repair (Discord recrée son dossier app-<version>)
Voulez tout remettre d'origine.\uninstall.ps1 ou node installer.mjs uninstall
Version déjà installée à mettre à jourRelancez l'installateur — il récupère le dernier payload/ depuis GitHub
