« Microsoft Defender SmartScreen a empêché le démarrage »

Ce message n'apparaît que si tu lances l'exécutable téléchargé par un navigateur. Voilà pourquoi, et comment le contourner.

✓ Aucun problème avec la méthode A

SmartScreen ne s'active que sur un exécutable téléchargé par un navigateur (Windows y colle la marque « Mark of the Web »). La commande PowerShell appelle Invoke-WebRequest : les fichiers récupérés n'ont aucune marque, Unblock-File la retire au besoin, et aucun .exe n'est exécuté. Le payload installé est du JavaScript chargé par Discord — rien que Windows puisse bloquer.

⚠ Ce n'est pas un virus

Cause : noxtcord.exe est un exécutable non signé numériquement et téléchargé depuis Internet. Windows applique la marque « Mark of the Web » et SmartScreen bloque tout binaire inconnu. C'est le comportement par défaut de Windows pour n'importe quel exe sans réputation — Defender l'a pourtant scanné et le trouve propre.

  1. Depuis la fenêtre d'avertissement : Plus d'informations → Exécuter quand même.
  2. Ou débloquez le fichier : clic droit → Propriétés → cocher Débloquer → OK.
  3. Ou en PowerShell : Unblock-File -LiteralPath "C:\chemin\vers\noxtcord.exe"

Solution définitive : la signature du code via SignPath (gratuite pour les projets open source) + soumission du fichier à Microsoft.
