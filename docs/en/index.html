// how it works

What does it actually do?

Four steps, all reversible, touching nothing but Discord.

1

Backup

The installer renames resources\app.asar to _app.asar. Your original Discord stays intact and can be restored at any time.

2

Mini app.asar

A tiny app.asar is written: its index.js just does require("%APPDATA%\Noxticord\dist\patcher.js").

3

Copy the payload

The contents of payload/ (patcher, bundles, CSS, Monaco) are copied into %APPDATA%\Noxticord\dist from GitHub.

4

Relaunch

Discord restarts and the NoxtiCord build takes over. A “Update and restart” toast announces new versions.

“Microsoft Defender SmartScreen prevented an app from starting”

This message only appears when you launch an executable downloaded by a browser. Here is why, and how to get around it.

✓ You won't see this with method A

SmartScreen only kicks in for an executable downloaded through a browser (Windows attaches the “Mark of the Web”). The PowerShell command just calls Invoke-WebRequest: the files it fetches carry no mark at all, Unblock-File removes it when needed, and no .exe is executed. What gets installed is plain JavaScript loaded by Discord — nothing Windows can block.

⚠ It is not a virus

Cause: noxtcord.exe is an executable that is not digitally signed and downloaded from the Internet. Windows applies the “Mark of the Web” and SmartScreen blocks any unknown binary. That is the Windows default for any exe without reputation — Defender scanned it and found it clean.

  1. From the warning window: click More info → Run anyway.
  2. Or unblock the file once and for all: right-click → Properties → tick Unblock → OK.
  3. Or in PowerShell: Unblock-File -LiteralPath "C:\path\to\noxtcord.exe"

Permanent fix: code signing with SignPath (free for open source) + submitting the file to Microsoft.
